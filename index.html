02 — Publications

The Bidding Games: Reinforcement Learning for MEV Extraction on Polygon Blockchain arXiv:2510.14642 · main author 2025

On a blockchain the order of transactions inside a block is itself worth money, and searchers compete in an auction for the right to set it. We model that auction — Polygon's Atlas — as a learning problem: a simulation environment for the auction dynamics, and a PPO agent that bids inside real-time latency budgets. Deployed alongside existing searchers the agent reaches 49% Maximum-Profit Capture, and improves substantially on baseline strategies under counterfactual evaluation.

Read on arXiv

Learning velocity model for complex media with deep convolutional neural networks arXiv:2110.08626 2021

Recovering the velocity structure of a complex medium from boundary measurements — the seismic inverse problem, in an acoustic setting. Forward modelling uses the grid-characteristic numerical method; the inverse direction is learned by deep convolutional networks. We modified the baseline UNet and showed a statistically significant gain in how closely the recovered velocity profiles match ground truth.

Read on arXiv

Online detection of failures generated by storage simulator Journal of Physics: Conference Series 1740 2021

Real failure data from storage hardware is scarce, so we generated it: a discrete-event simulator in Go that reproduces the structure and dynamics of high-level storage building blocks. On top of that, an adapted change-point detection algorithm — density-ratio estimation via binary classifiers — finds failures online in the resulting time series. The point is to catch a failing component early in a data centre holding thousands of devices.

Read in JPCS · arXiv

Space Navigator: a Tool for the Optimization of Collision Avoidance Maneuvers Advances in the Astronautical Sciences 170 · main author 2020

Satellites in low orbit have to dodge debris, and every maneuver costs propellant that cannot be replaced. The paper describes a system that estimates collision probability for a pair of space objects and searches for the maneuver that avoids the collision at the smallest fuel cost, using reinforcement learning over a simulated orbital environment.

Read on arXiv

SANgo: a storage infrastructure simulator with reinforcement learning support PeerJ Computer Science 2020

A simulator of a hybrid distributed storage system, built so that reinforcement learning agents can be trained against it rather than against production hardware. It reproduces the behaviour of the real system closely enough to tune policies, and exposes the interfaces an RL loop needs.

MentorFocus Social project · Telegram 2026

A free Telegram space where people get their day done side by side. You write down a morning plan — by voice or text — and land in a small team of three for the day. Everyone is anonymous, plans are softened before the team sees them, and when someone closes a task the others can quietly cheer. No streaks, no guilt for skipping a day — come daily or once a year, both are fine.

Built and run solo: the bot, the matching, the language model that parses plans and keeps private things private. Free by design — the goal is a few features that work flawlessly, not a subscription.

06 — Projects

QuantProfile Own product · Interview training 2026

A training site built around questions that were actually asked in interviews for quantitative research, applied machine learning and fraud detection — not invented ones. Each question carries a short answer written the way you would say it out loud, and a note on what the question is really probing for.

  • You answer in your own words, by typing or by voice, and a model grades the answer against the reference — the score decides when the question comes back. Topics carry their own repetition weight: gradient boosting returns often, LLM systems rarely.
  • The profile is the point of the name: activity by day, a streak, overall progress — shareable as a link or an embeddable image. Something to send a recruiter instead of claiming you know the material.
  • Progress lives in the reader's own browser. No accounts to create, no keys to paste, nothing sent anywhere it does not need to go.

trading-research-pipeline Python · MIT 2026

A leakage-aware research pipeline for systematic trading, and what it found when pointed at crypto perpetuals. The whole path from raw events to a trading result: data contracts, feature engineering, forward-looking labels, chronological validation with purging and embargo, model comparison, and a backtest that charges realistic costs.

  • Short-horizon cross-sectional reversion pays — but only under a market state that can be measured and, on this evidence, not forecast. On a held-out fortnight a three-parameter rule earns +6.99 bp per trade net of costs on 22 of 26 instruments; a model of how far each trade runs raises it to +18.8 bp over 3,297 trades. On the six weeks that followed, with the state absent, the identical frozen configuration loses on all 26.
  • Everything else in the register is negative, established the same way — every candidate, its status, and the condition written down before the test that would refute it.
  • The emphasis is on the parts that decide whether a result means anything: validation and cost accounting, not the model. Leakage is a test that fails, not a caveat in a footnote.
